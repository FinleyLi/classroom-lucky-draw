# classroom-lucky-draw
小教學工具｜課堂抽籤系統，老師下載打開就能用，不用寫程式，人數依名單自動調整

## 👩‍🏫 適合誰使用

- 需要課堂抽籤點學生上台回答問題的老師
- 需要公平隨機分組、輪流發言順序的老師
- 想要一個簡單、不用註冊帳號、不用網路教學平台的小工具

## ✨ 特色

- **不重複抽籤**：抽過的學生會從剩餘名單中移除，不會再次被抽到，確保每位學生都有公平機會
- **人數彈性**：學生名單一行一位，人數不寫死，套用名單時自動計算總人數，換班級、換課程都能直接用
- **公平隨機**：每次抽籤都是從當下剩餘名單中等機率隨機抽出，動畫效果不影響抽籤結果
- **抽籤紀錄**：即時顯示歷次抽中名單，方便老師記錄與回顧
- **免安裝、免帳號**：純網頁檔案，用瀏覽器打開即可使用，不需要寫程式或架設伺服器

## 🚀 怎麼使用

1. 下載 `class_lucky_draw_15.html` 這個檔案
2. 用瀏覽器（Chrome、Edge、Safari 等）直接打開它
3. 在右側「學生名單」欄位，一行輸入一位學生姓名
4. 點擊「套用名單」
5. 點擊「開始抽籤」（或按空白鍵）開始抽籤
6. 抽完想重新來一輪，點擊「重新開始」即可讓所有學生重新加入待抽名單

> 💡 小提醒：這個工具不需要網路連線就能用，上課前先打開頁面、套用好名單，之後就算教室網路不穩也不影響使用。

## 📋 名單輸入規則

- 每行一位學生，姓名不可空白
- 姓名不可重複（不分大小寫）
- 單一姓名長度上限 30 個字元
- 至少需要 2 位學生才能套用名單

## ⚠️ 注意事項

- 抽籤結果只保存在目前瀏覽器分頁中，重新整理頁面後會清空，需要重新套用名單
- 名單中若含有真實學生姓名，請注意個資保護，避免公開分享含有真實姓名的畫面截圖或檔案

## 🛠️ 給想自行修改的老師／開發者

本工具用 HTML、CSS（Tailwind）、JavaScript 寫成，是單一檔案、沒有後端或資料庫，抽籤結果只存在瀏覽器記憶體中。抽籤演算法：每輪從剩餘名單中以 `Math.random()` 等機率抽出一人，抽中後立即從剩餘名單移除，確保不重複且公平。想調整顏色、文字或功能，直接打開檔案編輯即可，不需要額外安裝任何工具。
