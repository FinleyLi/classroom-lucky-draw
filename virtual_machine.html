2既有 VM 移轉方式

原則採逐步移轉，不做一次性全面搬遷

可重新建置的服務

PVE 建立新 VM
→ 購置所需 Windows License
→ 重新安裝 OS／服務
→ 移轉資料
→ 測試後正式切換

無法重新安裝的既有系統

  • 優先方式：Nutanix → Clonezilla → PVE
  • 轉移困難時：Nutanix → VMware Converter → ESXi → PVE

備註：ESXi 於此僅作為移轉過渡工具，非正式規劃中的虛擬化平台；且免費 ESXi 8 有實際限制，如：每台 VM 上限 8 vCPU、無法連接 vCenter（僅能單機管理）、不支援 vMotion／HA／DRS、無 Broadcom 官方支援，僅適用於非正式生產環境的短期過渡。

4平台比較

Proxmox VE vs Hyper-V vs Nutanix AHV vs VMware vSphere

評估項目 Proxmox VE Hyper-V Nutanix AHV VMware vSphere
授權成本 核心功能免費；支援訂閱自 EUR 120／socket／年起（Community 層級） 隨 Windows Server 授權內含，另需 Windows Server 授權費用 依節點訂閱，per-TiB／per-core 計費 Broadcom 收購後改訂閱制，取消永久授權，並有最低核心數綁定套裝
商業模式 核心開源免費，選配訂閱支援 隨 Windows Server 授權內含，成本綁定於 Windows Server 授權 依節點訂閱制，三節點為最低部署門檻 訂閱制、套裝組合（VMware Cloud Foundation／vSphere Foundation），並有最低核心數綁定計費
Container 支援 原生支援 LXC，Docker 需透過 VM 執行 Windows Containers、WSL2 透過 Nutanix Kubernetes Engine 支援 Kubernetes 透過 Tanzu Kubernetes Grid 支援容器編排
Backup 以 NAS 為主要備份目標、Proxmox Backup Server另支援 S3 相容儲存；Veeam（2024 年起支援） Veeam、Azure Backup、原生備份功能 Nutanix Mine、Veeam、HYCU 過往經驗使用Synology Active Backup for Business 為主要備份方案
資料來源：Virtually Pro（2026）〈Proxmox vs Hyper-V vs Nutanix – VMware Replacement Comparison〉；HorizonIQ（2025 年 8 月）〈Nutanix vs VMware vs Proxmox〉。VMware 欄位僅列來源明確提及之內容；PVE 授權金額已依 Proxmox 官方 2026 年公告價格核對更新；PBS 支援 S3 相容物件儲存為官方既有功能之補充說明。實際功能、授權及價格仍以各原廠最新公告為準。
